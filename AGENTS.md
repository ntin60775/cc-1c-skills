# Проект: cc-1c-skills

Это репозиторий навыков (skills) для AI-агентов, работающих с платформой **1С:Предприятие 8.3**.

## Назначение

Набор даёт модели готовые абстракции над XML-форматами выгрузки 1С и CLI конфигуратора:
- создание и редактирование конфигураций, расширений (CFE), внешних обработок (EPF) и отчётов (ERF);
- управление метаданными, формами, ролями, подсистемами, макетами, СКД;
- веб-публикация через portable Apache и тестирование через веб-клиент (Playwright);
- запись видеоинструкций с субтитрами, подсветкой и TTS-озвучкой.

## Структура репозитория

- `.agents/skills/` — каталоги навыков (по одному на skill). Каждый содержит `SKILL.md` и скрипты.
- `docs/` — гайды по группам навыков и спецификации XML-форматов 1С.
- `scripts/` — скрипты установки навыков в проекты (`switch.py`) и синхронизации с upstream.
- `knowledge/` — проектная память: задачи (`tasks/`), операции (`operations/`), модули (`modules/`).
- `tests/` — тесты навыков.

## Соглашения

- Навыки построены на открытом стандарте Agent Skills и совместимы с Claude Code, Kimi CLI, Cursor и др.
- Рантайм — Python 3 (кросс-платформенный).
- XML-файлы генерируются в UTF-8 с BOM.
- Каждый skill автономен: `SKILL.md` описывает параметры, команды и примеры.
